# sooamo.github.io

My portfolio site. I'm Sooa Mo, a UX/UI and graphic designer based in Metro Vancouver, BC.

**Live:** https://sooamo.github.io

## What's here

Case studies for my work, school, and personal projects.

## How it's built

Plain HTML, CSS, and JavaScript, with Bootstrap for the image modal and some page layouts. No build step. The navbar and footer live in `partials/` and get pulled into each page by `js/include.js`.
